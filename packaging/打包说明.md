# EXE 打包说明（预留配置，首版不执行）

## 前置条件

```bash
pip install -r requirements.txt
pip install pyinstaller -i https://pypi.org/simple
```

## 打包

必须在只安装 `requirements.lock.txt` 的干净虚拟环境中构建，避免
Anaconda、Jupyter、Matplotlib 等无关可选依赖被错误收集并显著放大产物。

```powershell
python -m venv .venv-build
.\.venv-build\Scripts\python -m pip install --index-url https://pypi.org/simple -r requirements.lock.txt
```

在项目根目录执行：

```bash
pyinstaller packaging/pyinstaller.spec --distpath dist --workpath build --clean
```

产物：`dist/见舟工作台.exe`，双击即启动本地服务并打开浏览器。

## 设计决策

1. **单文件 onefile 模式**：`pyinstaller.spec` 已按单文件配置，前端 `frontend/` 目录作为数据资源打入；
2. **console=True**：保留控制台窗口，方便查看服务日志与 Trace ID（本产品「无静默兜底」原则要求错误可见）；
3. **数据目录**：开发模式默认使用项目下的 `data/`；EXE 模式使用
   `%LOCALAPPDATA%/JianzhouMediaWorkbench/`，避免 onefile 临时解压目录和程序安装目录不可写造成数据丢失。
   可通过 `JIANZHOU_DATA_DIR` 显式指定数据目录。
4. **首次运行初始化**：自动建表 + 写入演示数据；删除 `data/app.db` 即可重置；
5. **端口**：默认 8741；若被占用，设置环境变量 `JIANZHOU_PORT` 后重试；
6. **icon**：预留 `icon=None`，可替换为 `packaging/jianzhou.ico`。

## 常见问题

- **杀软误报**：PyInstaller 单文件产物可能被误报，可加白名单或改用 `--onedir` 目录模式；
- **uvicorn hiddenimports**：spec 中已显式声明，勿删；
- **启动慢**：onefile 解压需 2-5 秒，属正常现象；介意可改 onedir。
