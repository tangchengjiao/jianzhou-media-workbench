# 封面内容契约与图文预览验收

## 审查范围

- 稿件/项目自动填入封面字段
- 一键优化提示词
- 本地模板排版
- AI 完整成图提示词
- 图文文档历史预览

## 根因

1. 项目标题、差异化方向、运营目标、大纲和关键词被直接映射为可见封面文字。
2. 核心主题与主标题同时排版，没有去重。
3. 图片提示词没有区分“仅供理解的内部上下文”和“允许出现在画面的文字”。
4. 图文历史的预览图使用满宽卡片，外层详情和图片自身都缺少内边距。

## 修复后的链路

1. 项目只自动填入核心主题和唯一主标题；运营目标、大纲不再默认上画面。
2. 前后端共同净化字段，过滤运营指标、内容分类、热点标签和证据 ID。
3. 画面文字白名单固定为：一个主标题、一个可选副标题、最多两个短标签。
4. 核心主题、领域和关键词只参与语义理解；本地模板不再重复排版核心主题。
5. AI 完整成图提示词末尾追加逐字白名单，禁止模型补写栏目名、指标和解释小字。
6. 图文历史固定最多三列，卡片和预览图增加双层留白与圆角边界。

## 验证

- 反向输入：`收藏率 > 账号均值`、`观点型`、`市场热点`、`SG-HOT-*`。
- 结果：上述内部字段均未进入本地封面可见文字或最终生成提示词。
- 自动化测试：86/86 通过。
- 运行态：`source`，`/healthz` 正常；前端 JS/CSS 均返回 200 并包含新规则。
- 验收图：`sanitized-local-cover.png`。

本轮完成了代码级、接口级、本地渲染和运行态静态资源验收；未声明完整 WCAG 合规，键盘、读屏器和真实图片 Provider 的逐像素人工验收仍属于独立验收范围。
