# 统一资产、动态运营与视觉双工坊执行方案

日期：2026-08-06

## 目标

把现有分散的自有作品、雷达信号、提取文本、拆解、稿件、视觉结果、发布和复盘连接为一条可追溯、可搜索、可复用的真实数据链；同时将视觉工厂拆成封面与图文两套工作流，并解决模板单一、文本溢出和历史扁平化问题。

## 不变原则

1. 原始媒体、字幕、ASR、原文和历史稿件不可覆盖。
2. 新资产只建立索引和关系，不复制或伪造业务数据。
3. AI运营建议只能生成草案，不自动修改稳定IP档案或正式排期。
4. 真实模式不回退演示数据；缺数据必须明确展示。
5. 视觉生成失败必须保留真实失败原因，不返回占位假图。
6. 本轮只运行源码；不打包EXE。

## Phase 0：安全基线

- 完整复制当前工作区、Git历史、配置和数据目录。
- 生成SQLite一致性备份并执行完整性检查。
- 记录现有资产数量、缺失关系和测试基线。

验收：备份目录存在；数据库完整性为 `ok`；可从备份恢复。

## Phase 1：统一资产与关系模型

新增：

- `asset_records`：统一索引现有来源、文本、拆解、稿件、视觉、发布和复盘对象。
- `asset_relations`：记录来源、衍生、引用、发布和复盘关系。
- `asset_collections` / `asset_collection_items`：收藏夹与项目合集。
- `account_work_source_links`：自有作品与来源内容的稳定关联。
- `visual_batches`：一次视觉请求对应一个批次，现有 `cover_projects` 继续作为批次中的具体成品。
- `operation_context_snapshots`：记录每次运营建议使用的真实资料和数据缺口。

迁移后回填现有数据，不删除旧表、不改变旧主键。

验收：现有数据数量不减少；每个可用对象有资产索引；孤立关系可报告。

## Phase 2：统一资产中心

把原“资料中心”升级为：

- 总览
- 全部资产
- 原始内容
- 提取文案
- 拆解与模式卡
- 创作稿件
- 视觉资产
- 发布与复盘
- 数据包与导入

能力包括搜索、类型/平台/来源/状态筛选、排序、详情抽屉、完整原文、上下游来源链、收藏、加入合集和继续处理。

验收：不离开资产中心即可找到并打开任意历史原文、拆解、稿件或视觉结果，并继续进入下一步。

## Phase 3：自有作品完整链路

- 自有作品提取时写入稳定的作品—来源关联。
- 已有成功任务按 `account_work_id`、URL和平台作品ID回填关系。
- 作品卡显示：仅元数据 / 已提取 / 已拆解 / 已创作 / 已发布 / 已复盘。
- 运营分析可以区分“理解了正文”和“只有互动指标”。

验收：从自有作品可以追到原文、拆解、稿件和复盘；重复提取优先复用本地资产。

## Phase 4：动态运营上下文

运营画像同时读取：

- 自有作品近30/90天指标、人工标记和提取覆盖率；
- 自有高低表现内容的语义与结构差异；
- 对标新作与高表现内容；
- 平台热榜、行业数据源、关键词、用户反馈、历史起量和手动关注；
- 当前IP档案、运营周期、预测、发布快照和复盘规律。

每条建议保存并展示证据ID、依据摘要、时间窗口、置信度和数据缺口。

验收：建议可追溯；没有正文时明确降级；用户确认前不进入排期。

## Phase 5：视觉双工坊

### 封面工作室

单张主视觉、候选生成、平台比例、人物与品牌资产、候选比较和选定。

### 图文工作室

先生成/编辑页面大纲，再按封面、痛点、观点、步骤、案例、清单、总结等页面角色生成；支持排序、锁定和单页重生成。

验收：图文不再只是把封面卖点机械拆页；两种工作流字段和生成协议独立。

## Phase 6：自适应模板与批次管理

内置四套统一品牌体系：

1. 科技发布会：深蓝、HUD、人物右置、标题左置。
2. 知识便签：纸张/便签信息层级，适合方法和清单。
3. 极简留白：高可读性、弱装饰、适合知识观点。
4. 黑橙工具测评：强对比、适合产品和工具内容。

排版引擎必须支持：

- 标题安全区、人物安全区和平台裁切安全区；
- 基于可用宽高动态换行与字号缩放；
- 标题过长时逐级降级，禁止裁切；
- 卖点芯片自动换行，空间不足时减少数量并记录提示；
- 不同宽高比使用独立构图参数；
- 生成后执行边界检测，发现溢出则自动重排；
- 模板使用真实PNG预览，不使用空色块代替。

一次请求写入一个 `visual_batch`；历史先展示批次，再展开候选或页面。

验收：极长中文标题、长副标题和5个卖点在所有支持比例下均不越界；批次可重命名、复用和软删除。

## Phase 7：验收

- 数据库迁移、回滚和完整性测试。
- 资产索引、来源关系和用户隔离测试。
- 运营上下文证据与数据缺口测试。
- 封面极限文案、所有模板和比例的边界测试。
- 图文页面顺序、锁定和单页重生成测试。
- API、全量单元测试和浏览器用户路径测试。
- 刷新、重启、重复点击、空数据、失败重试和真实/演示隔离测试。

验收：无阻断错误；所有失败有明确原因；应用重启后资产、批次、建议与关系完整保留。

- 数据库已升级至 schema v17，`PRAGMA integrity_check = ok`。
- 已建立统一资产索引、上下游关系、资产合集、自有作品正文关联、运营上下文快照、视觉批次和视觉修订关系。
- 资料中心已升级为统一资产中心，支持检索、类型/平台/来源筛选、排序、收藏、详情、完整正文、上下游关系和合集。
- 自有作品卡会显示“仅元数据 / 已提取 / 已拆解 / 已创作 / 已有视觉 / 已发布 / 已复盘”。
- 动态运营顾问会读取自有作品语义与表现、雷达信号、IP档案和复盘，并展示正文覆盖率、拆解覆盖率、信号类别、复盘数和数据缺口。
- 视觉工厂已拆分为封面与图文两套流程；图文支持分镜生成、人工修改、排序与锁定。
- 内置 4 套自适应模板；模板预览均为真实 PNG；极长标题、长副标题和多卖点会在安全区内缩放、换行、截断或省略。
- 每次视觉请求保存为独立合集；支持改名、整组复用、整组删除、候选选定和单页追加 v2 修订；旧版不覆盖。
- 新增专项回归测试，最终全量结果为 `59 passed`。
- 源码服务已从当前工作区启动在 `http://127.0.0.1:8741`；本轮未打包 EXE。
