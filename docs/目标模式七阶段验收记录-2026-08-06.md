# 目标模式七阶段验收记录（2026-08-06）

## 本轮边界

- 不打包 EXE；保持源码服务运行，交由用户实际体验后再决定发行。
- 参考现有 Skill 的合理原则，不复制其命令、目录或独立工作流。
- 真实模式外部服务失败时明确报错，不回填演示数据，不自动切换供应商。

## 七阶段交付

1. **安全基线**：已建立工作区、SQLite 一致性快照与 Git bundle 恢复点。
2. **数据底座**：数据库升级到 schema v13；同一用户只允许一个激活 IP 档案；档案切换、发布登记等关键写入使用事务；模型空响应禁止保存为空白稿件。
3. **访谈与 IP 档案**：原始访谈轮次不可覆盖；摘要、校正版逐字稿、标签和备注按修订版本保存；字段候选可人工编辑、确认/拒绝，并在变更预览后生成新的不可变 IP 档案版本。
4. **AI 发布前预测**：AI 根据当前稿件、IP 上下文与历史复盘生成可解释预测；显示维度、依据、风险、反事实与校准样本；用户只负责复核/说明；锁定后保存完整性哈希，旧预测版本保留。
5. **发布与复盘**：登记发布时绑定最新已锁定预测并原子创建 T+1/T+3/T+7 计划；快照支持播放、赞、评、藏、分享、关注、完播率等；同节点校正只追加不覆盖；复盘追加预测观察，规则建议仍需用户确认。
6. **动态运营与封面资产**：近 30/90 天真实账号作品生成动态运营画像；AI 周计划为待确认草案，确认后才进入正式排期，永不自动修改稳定 IP；封面支持人物原图存档、内置/自有模板、字段自动补齐、3:4/9:16/16:9/1:1 与本地 PNG 预览存档。
7. **整体验收**：48 个 Python 单元/契约/隔离链路测试通过；Chrome 12 页面逐页渲染通过；17 项浏览器冒烟检查通过；无严重浏览器控制台错误；SQLite integrity_check=ok，foreign_key_check=0。

## 新增主要入口

- IP 档案：历史访谈与存档、候选人工修订、变更预览并应用。
- 创作工坊：AI 发布前预测、版本锁定、人物参考图、封面生成与保存。
- 账号运营：动态运营顾问、30/90 天画像、AI 周计划草案确认/拒绝。
- 数据复盘：扩展真实快照指标、预测/实际对比与只追加观察。

## 已知外部边界

- 视频号等平台能返回哪些字段仍受 TikHub 上游接口真实能力约束；缺失的粉丝数、封面或媒体地址会明确显示缺失，不伪造。
