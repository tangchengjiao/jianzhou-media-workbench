# PRD V2.1 修订说明

> 本文件与《自媒体个人运营工作台_产品需求文档_PRD_v2.0.md》共同构成 **PRD V2.1**。
> 修订依据：docs/审核报告_三文档一致性_v2.0.md（2026-08-01 审核），优化方案已经用户确认。

---

## R1 品牌命名统一（对应 P1-2）

产品正式名称：**见舟 · 自媒体运营工作台**，简称「见舟工作台」。
所有界面、文档、打包产物统一使用该名称。演示创作者「林小舟」为首版内置演示数据包。

## R2 新增章节：外观与主题（对应 P0-5）

### 主题要求

- 提供**浅色**与**深色**两套完整主题，一键切换；
- 切换入口固定在顶栏，操作即时生效、无需刷新；
- 用户偏好持久化保存，下次启动自动恢复；
- 首次启动默认浅色主题；
- 侧边栏在浅色主题下同样改用浅色表面，不再固定深色；
- 所有状态色（成功/警告/错误/信息）在两种主题下均须保证对比度可读。

### 验收

- 任意页面切换主题后无未适配的硬编码颜色；
- 弹层、Toast、图表、看板、时间线全部双主题可用。

## R3 语音访谈交互规格补充（对应 P0-3）

访谈进行中页面必须包含：

1. 对话区：操盘手问题与用户回答按轮次展示，语音模式下同步展示实时转写文本；
2. 进度区：当前主题、第 N 问 / 预计 M 问、已用时长；
3. 控制区：按键说话 / 暂停 / 结束访谈 / 切换文字模式（**用户显式选择，且记录模式来源**）；
4. 结束后进入字段候选确认流：逐条展示字段、值、类型（explicit / summarized / inferred）、证据引用，用户逐项确认或拒绝后才生成档案版本草稿；
5. 中断的会话可在 IP 档案页恢复，中断不得生成「建档成功」的假结果。

语音传输：首版采用 **REST 音频分片上传 + 轮询状态**（修订技术方案 §4.1 的 WebSocket 描述，WS 列为实时模式后续可选升级）。

## R4 内容库存状态集合对齐（对应 P1-1）

以后端状态机为准（10 主状态 + 3 可选状态）：

```text
CANDIDATE → SELECTED → OUTLINING → DRAFTING → PRODUCING
→ READY_TO_PUBLISH → PUBLISHED → WAITING_RETRO → RETRO_COMPLETED → ARCHIVED
可选：PAUSED / CANCELLED / BLOCKED
```

界面映射：看板列 = 候选 / 已选题 / 提纲中 / 写作中 / 制作中 / 待发布 / 已发布 / 待复盘；「已完成·归档」以筛选视图呈现，不占看板列。

## R5 雷达信号卡修订（对应 P1-3）

- 卡片必须包含「链接」入口（图标形式）；
- 动作全集：加入观察 / 获取评论 / 提取文案 / 深度拆解 / 转为选题 / 忽略 / 不再推荐相似，按信号类型给出可用子集，但「获取评论」不得缺席（点击后生成评论获取的执行计划，同样需确认）。

## R6 显式授权修正（对应 P0-4）

执行计划确认卡中「无原生字幕时继续：下载媒体并 ASR」**默认不勾选**；用户勾选动作本身写入任务授权记录（authorizations）。

## R7 演示数据规范（对应 P1-10，新增）

- 系统提供显式**演示模式**（DEMO_MODE，默认开启）：全部外部数据来自内置演示 Provider；
- 演示模式下 UI 全局展示「演示数据」徽标，每个演示产物标注来源为 demo；
- 演示模式是用户可见、可在系统设置中关闭的状态，**不属于静默兜底**；
- 配置真实 API Key 并关闭演示模式后，相同链路走真实适配器；真实适配器失败按无兜底原则显式报错。

## R8 其余界面修订

- 导航分组默认折叠，仅展开当前工作组（P1-6）；
- 表达画像按 12 项完整展示并标注来源（P1-5）；
- 创作工坊稿件工作区支持多平台版本标签页（P1-8）；
- 创作者切换实现确认弹层：展示将关闭与将激活的数据包清单，确认后清空会话上下文（P1-9）；
- 评论获取提供范围选项：热门 / 指定数量 / 全量分页，以及 只保存 / 保存后聚类（P2-3）；
- 顶栏日期动态显示；全局状态条（同步异常、今日成本）由后端聚合接口驱动（P2-7）。
