# Phase 2–5 真实链路验收报告

日期：2026-08-05

## 验收结论

本轮已建立一条不依赖演示兜底的主垂直链：

`真实音频上传 → 百炼 ASR → 不可变资产 → Context Resolver → DeepSeek 拆解 → 多平台创作 → 锁定发布前判断 → 发布登记 → T+1/3/7 计划 → 真实快照 → 复盘 → 人工审核规则版本`

真实 Provider E2E 共 12 项，通过 12 项；临时音频、临时数据库与临时加密凭据副本在验收后删除。

## 关键修复

1. 任务引擎增加幂等键、尝试次数、持久化步骤、租约、心跳、取消和重启恢复。
2. 核心对象查询改为当前创作者归属校验，跨用户与不存在统一返回 404。
3. 新增文件素材库、SHA-256 去重、不可变转写资产和证据事件。
4. 百炼 ASR 使用 OpenAI Compatible Audio 协议；业务级测试发现并移除了不被端点接受的 system 消息。
5. DeepSeek 输出增加严格 JSON 优先、完整 JSON 对象安全提取与前端 Schema 归一化。
6. 发布接口不再只返回“已创建计划”的文字，而是真实写入三条快照计划。
7. 无自动指标 Provider 时明确等待人工录入；复盘只基于真实快照。
8. 规则审核真实创建规则包版本；导入 commit/rollback 真实操作目标记录。
9. 前端增加真实音频上传、ASR 设置与测试、多平台稿件、快照录入和旧复盘兼容状态。
