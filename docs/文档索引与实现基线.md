## 代码实现状态声明

当前代码是演示型原型，不代表上述文档已经完整实现。任何能力必须按以下状态维护：

- `REAL`：真实依赖、真实数据和异常路径已经端到端验证。
- `DEMO`：明确标注的演示实现。
- `PARTIAL`：部分真实实现，但尚未完成业务闭环。
- `MISSING`：未实现。
- `FAKE_SUCCESS`：返回成功但没有完成宣称的业务动作；此状态必须优先消除。

README、冒烟测试数量和前端页面存在均不能单独作为功能完成证据。

## Phase 0/1 验收范围

- 干净数据目录可以启动并通过健康检查。
- 数据库具备版本化迁移、外键开启和关键索引。
- 运行数据写入稳定的用户数据目录，并允许显式覆盖。
- 配置项受白名单和结构校验约束；密钥不会通过设置接口回传。
- 启动与异常日志可定位，打包配置指向正确项目根目录。
- 自动化测试覆盖干净启动、迁移、配置安全和打包路径。

Phase 0/1 不把尚未实现的 Provider、LLM、STT 或完整内容闭环伪装为已完成。

## Phase 2 首个垂直切片

内容雷达已经具备对标账号的可操作入口，并贯通账号、作品、分析和雷达信号。抖音真实短链已经完成端到端验收；其他已开放平台只有官方接口映射，尚未完成逐平台真实样本验收，因此继续按 `PARTIAL` 管理，不以 Demo 流程代替真实验收。

## Phase 2.2 配置闭环

运行模式改为持久化设置并可即时生效；OpenAI Compatible 模型服务支持自定义 Base URL、鉴权方式、四类任务模型绑定、模型列表读取和最小生成测试。外部模型供应商尚未使用用户真实 Key 验收，因此只把“配置/路由/协议契约”标记为真实，不把外部模型可用性写成已完成。Embedding、STT、TTS 继续按未接入管理。
