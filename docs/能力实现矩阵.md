## 本轮明确未伪装为完成的边界

- 没有 Embedding 与历史语料相似度引擎，因此不生成“历史重复 0%”或“风格匹配 92%”。
- 没有平台授权指标采集 Provider 时，调度只标记待人工录入，不生成 T+N 演示指标。
- 没有实现平台媒体下载授权时，只支持用户上传真实音频走 ASR。
- 没有实现 TTS；设置页继续显示未接入。
- 本轮不构建 EXE，避免把尚待用户验收的源码重复封装。
