# 能力实现矩阵

更新日期：2026-08-04

状态口径：`REAL` 真实端到端验证；`DEMO` 明确演示；`PARTIAL` 部分实现；`MISSING` 缺失；`FAKE_SUCCESS` 返回成功但未完成宣称动作。

## 工程底座

| 能力 | 状态 | 当前证据 |
|---|---|---|
| 干净 Demo 启动 | REAL | 空数据目录启动、健康检查、38 项演示冒烟通过 |
| 干净 Real 启动 | REAL | 仅创建最小本地用户，不注入演示业务数据 |
| Real 模式缺配置失败 | REAL | 返回 `CONFIG_MISSING_API_KEY` Typed Error，不再因 Provider 方法缺失返回 500 |
| 数据库迁移 | REAL | schema v2、迁移校验和、迁移前备份、原子约束重建 |
| 数据完整性 | REAL | SQLite 外键、17+ 业务索引、事务/嵌套保存点、完整性诊断 |
| 稳定 ID | REAL | 新建记录改用 UUID；历史演示固定 ID 保留 |
| 密钥存储 | REAL（Windows） | DPAPI 加密，密钥不写入 SQLite、不通过设置 API 返回 |
| Provider 出站限制 | REAL | HTTPS、域名允许列表、私网/本机地址阻断、重定向阻断 |
| 上传上限 | REAL | 导入文件 10 MB、音频 25 MB，均可通过环境变量调整 |
| 本机访问边界 | REAL | 未实现认证前拒绝绑定非回环地址；响应增加安全头与 Origin 检查 |
| 日志 | REAL | 轮转日志写入稳定数据目录，未知错误向客户端隐藏内部异常 |
| PyInstaller | REAL | 干净虚拟环境构建并实际启动 EXE；首页、静态资源和空库初始化通过 |

| 工作总台 | DEMO | 聚合内容与建议大量依赖固定演示数据 |
