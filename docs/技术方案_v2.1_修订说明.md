## T1 前端技术路线锁定（对应 P0-2，修订 §1.2）

采用 **Vue 3 免构建方案**：

- Vue 3 全量运行时（vue.global.prod.js）本地内置，不依赖 CDN、不依赖 Node.js；
- 页面为 Vue 组件（模板字符串），按领域拆分 JS 模块；
- 无 TypeScript、无 Vite 构建步骤；
- FastAPI 直接挂载 frontend/ 静态目录，`python app.py` 单一入口即可运行；
- PyInstaller 打包时 frontend/ 作为数据资源打入。

放弃 §1.2 中「TypeScript + Vite」的要求，其余（Vue 3 / Pinia 式集中状态 / Vue Router 式哈希路由）以等效轻量实现保留：集中状态用 Vue.reactive store，路由用 hash router。

## T2 持久层锁定（修订 §1.2）

- SQLite（标准库 sqlite3）+ 自研轻量仓储层，写库前以 Pydantic 校验；
- 启动时自动建表（幂等 DDL），首版不引入 SQLAlchemy / Alembic；
- 复杂结构（信号卡、分析结果、执行计划、资产分层）以 JSON 列存储；
- FTS5 用于语料与转写全文检索（首版建表预留，检索接口列为 P1）。

## T3 语音传输通道锁定（对应 P1-4，修订 §4.1 / §14.2）

首版：**REST 分片上传 `POST /api/profile/interviews/{id}/turns/audio` + 轮询会话状态**。
WebSocket 实时流水线列为实时语音模式的后续升级，不在首版范围。
访谈模式：文字访谈完整实现；语音访谈在演示模式下由 Mock STT 转写并标注演示来源，真实 STT 走适配器接口（STTProvider Protocol 不变）。

## T4 演示模式（DEMO_MODE）技术规范（对应 P1-10，新增）

```python
# app/config.py
DEMO_MODE = os.environ.get("JIANZHOU_DEMO", "1") == "1"   # 默认开启
```

- 演示模式下，SocialDataProvider / LLMProvider / STTProvider 解析为 Demo 实现，返回确定性演示数据；
- 所有演示产物 `provider` 字段标记为 `demo_*`，前端展示「演示数据」徽标；
- `GET /api/settings/runtime` 返回 demo_mode，前端据此举全局徽标；
- 演示模式关闭且未配置 Key 时，真实适配器立即抛 `CONFIG_MISSING_API_KEY`（fail-fast，无兜底）。

## T5 API 补全（对应 P0-1，增补 §14）

### 14.8 系统设置与诊断

```text
GET   /api/settings                      # 全量设置（密钥脱敏）
PUT   /api/settings                      # 分区保存
GET   /api/settings/runtime              # demo_mode / 版本 / 数据目录
GET   /api/diagnostics                   # 数据源/模型/FFmpeg/存储 连通性
GET   /api/diagnostics/errors            # 最近错误（含 trace_id）
GET   /api/diagnostics/trace/{trace_id}  # Trace 查询
POST  /api/diagnostics/recheck           # 重新探测
```

### 14.9 用量与预算

```text
GET   /api/usage/summary                 # 今日/本月用量与预算进度
GET   /api/usage/ledger                  # 调用台账
```

### 14.10 成长记录

```text
GET   /api/growth/timeline               # 时间线事件
POST  /api/growth/events                 # 用户主动记录关键事件
GET   /api/growth/rules                  # 经验库（按状态筛选）
GET   /api/growth/export                 # 导出成长报告（不含密钥）
```

### 14.11 用户与包切换

```text
GET   /api/users                         # 创作者列表
POST  /api/users/{id}/activate           # 切换创作者（二次确认，清会话上下文）
GET   /api/packages/{id}                 # 数据包详情（含 §5.3 全字段）
GET   /api/packages/{id}/impact          # 删除影响计算
```

### 14.12 预测与快照补充

```text
POST  /api/creation/projects/{id}/prediction/lock   # 锁定发布前判断（只读化）
GET   /api/publications/{id}/snapshots              # T+N 快照查询
```

## T7 访谈授权记录（对应 P0-4 / R6）

`jobs.input_json.authorizations` 记录用户在执行计划中的显式勾选（如 `asr_when_no_caption: true`），默认 false；后端校验：无字幕且未授权时任务停在「待用户决策」，不得自动进入 ASR。
